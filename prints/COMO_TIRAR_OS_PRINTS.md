# Guia para Tirar os Prints do Sistema

Siga a ordem abaixo. Salve cada print com o nome exato indicado nesta pasta (`prints/`).

## Pré-requisito
1. Abra o terminal na pasta do projeto
2. Execute o backend: `cd backend && npm run dev`
3. Execute o frontend: `cd .. && npm run dev`
4. Acesse http://localhost:5173 no navegador

## Dica para prints no Windows
- **Snipping Tool**: Pressione `Windows + Shift + S` e selecione a área
- **PrtScn**: Captura a tela toda (cole no Paint e salve)
- **Extensão de navegador**: Use "Full Page Screen Capture" para capturas de página inteira

## Após tirar os prints
Os prints serão automaticamente referenciados na `DOCUMENTACAO_COMPLETA.md` pelas tags de imagem já inseridas.
